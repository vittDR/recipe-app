# Controls

- **Switch**: iOS size. On = `accent` (not green). Off = `line-strong`. A setting that has a value (a time) shows the value only while the switch is on.
- **Checkbox**: 26px circle. `accent` when selecting days or options, `sage` when marking what you already have.
- **Segmented control**: `stack` track, selected segment `surface` with a 1px shadow. Only for small fixed counts (pans: 1 / 2 / 3 / 4+). Never as tabs on a recipe page.
