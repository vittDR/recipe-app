# Recipe list triage (names 1–240)

Every name on the draft list, with its cuisine and a decision. The framework
behind the decisions is in [recipe-library-plan.md](recipe-library-plan.md).

- **Keep**: stays as it is.
- **Rework**: stays, turned into the real dish of a cuisine (the note says which) or given more protein.
- **Merge**: the same dish as another entry with a different protein or filling; the other entry stays.
- **Cut**: low protein (under the 25 g brief), a side, starter or snack rather than a dinner, a generic combination, or one too many of a format.
- **Seed duplicate**: the seed library already has this dish. Cut it if the list adds to the seed library; keep it if the list replaces it.
